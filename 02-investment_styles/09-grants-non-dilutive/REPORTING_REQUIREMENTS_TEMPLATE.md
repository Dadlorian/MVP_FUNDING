## Common Reporting Issues & Solutions

| Issue | Prevention | Solution |
|---|---|---|
| **Late reports** | Set calendar reminders 2 weeks prior | Contact program officer immediately if delayed |
| **Missing documentation** | Establish filing system immediately | Request extension while gathering docs |
| **Budget overruns** | Track monthly vs. quarterly | Seek program officer approval for reallocation |
| **Unclear metrics** | Document success criteria upfront | Use historical data to reconstruct evidence |
| **Inaccurate charges** | Review timesheets monthly | Amend with signed correction and explanation |
| **Lost receipts** | Scan receipts immediately | Use bank statements as backup documentation |
